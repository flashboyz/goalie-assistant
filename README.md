# 🥅 Личный вратарский помощник

Мини-приложение для хоккейного вратаря: ментальная подготовка, карточки, тесты, аудио и дневник игр.
Тёмный неоновый интерфейс для телефона.

## Что внутри
- **Главная**: «Ты готов! Сила внутри», быстрый доступ к разделам и время ближайшей игры с обратным отсчётом
- **Карточки**: 12 коротких подсказок для подготовки и для сложных моментов на льду, листаются стрелками
- **Тесты**: 12 вопросов, итог в процентах и лучший результат
- **Аудио**: 6 коротких треков (дыхание, настрой, уверенность), озвучка голосом устройства (Web Speech API)
- **Дыхание**: упражнение «вдох 4 секунды, выдох 6» с анимацией, таймером на 1, 3 или 5 минут, разными звуками и вибрацией на вдох и выдох (вибрация работает на Android)
- **Дневник**: настроение, «что было хорошо» и «что можно улучшить», статистика игры (бросков и голов, процент отражённых до и после 4-го гола)

## Как запустить
Весь проект — один файл `index.html`. Откройте его в браузере или включите GitHub Pages
(Settings → Pages → Branch: main → Save), и приложение откроется по постоянной ссылке.

## Данные
Дневник, результаты тестов и время игры хранятся только в браузере (localStorage) на том устройстве, где открыта страница.
Страница не может присылать уведомления, пока закрыта, поэтому напоминание лучше поставить в календаре телефона.

## Технические заметки
- Фото в шапке встроено в `index.html` (base64), поэтому файл весит около 150 КБ
- Шрифты Russo One и Oswald подгружаются с Google Fonts; без интернета покажутся системные
- Логика квиза, аудио и дневника — на чистом JavaScript, без библиотек
