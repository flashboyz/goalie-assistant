# 🥅 Личный вратарский помощник

Мини-приложение для хоккейного вратаря: ментальная подготовка, квиз, аудио и дневник игр.

## Что внутри
- **Карточка**: подготовка перед игрой и «Помни на льду», время ближайшей игры с обратным отсчётом
- **Квиз**: 12 вопросов, сохраняется лучший результат
- **Аудио**: озвучка советов голосом телефона (Web Speech API)
- **Дневник**: игры и тренировки, процент отражённых до и после 4-го гола, настроение

## Как запустить
Весь проект — один файл `index.html`. Откройте его в браузере или включите GitHub Pages
(Settings → Pages → Branch: main → Save), и приложение откроется по постоянной ссылке.

## Данные
Дневник и результаты квиза хранятся только в браузере (localStorage) на том устройстве, где вы открыли страницу.
