# Goalie Mentor

Помощник хоккейного вратаря: карточки, тест, озвучка, дыхательная практика и дневник.

## Текущая версия

- Регистрация и вход по почте и паролю через Supabase Auth.
- Сохранение, загрузка и удаление личных записей дневника в PostgreSQL.
- Доступ только к своим записям (Row Level Security).
- Перенос гостевого дневника текущего браузера в аккаунт без дублей.
- Тесты, ближайший матч и вибрация пока сохраняются на устройстве.
- 12 карточек, 12 вопросов, 6 сценариев озвучки голосом устройства.
- Дыхание 4/6: 30 секунд, 1 или 3 минуты.

## Структура и запуск

Корневые `index.html` и `assets/` — готовая сборка для GitHub Pages: ветка `main`, папка `/ (root)`.
Папка `app/` содержит исходники, схему базы и тесты. Для разработки нужны Node.js 22.12+ и pnpm.

```sh
cd app
pnpm install --frozen-lockfile
```

Создайте `app/.env.local` по образцу `.env.example`. Укажите URL проекта Supabase и Publishable key (`sb_publishable_...`). Публичный ключ входит в браузерную сборку; данные защищены авторизацией и политиками базы. Пароль базы и secret/service_role ключи в клиенте не используются.

```sh
pnpm dev
pnpm test
pnpm build
```

После сборки обновляйте корневые `index.html` и `assets/` из `app/dist/`, затем отправляйте изменения в main. Не публикуйте локальные настройки, зависимости и тестовые снимки. Браузерная проверка: `tests/browser-smoke.mjs` (Playwright и сервер на порту 5173).

## База и ограничения тестовой версии

В новом проекте Supabase выполните `app/supabase/migrations/001_diary.sql` один раз. Повторно запускать её в существующей базе не требуется.

Подтверждение почты отключено владельцем для закрытого тестирования. Перед публичным запуском нужны подтверждение адресов, доставка писем и восстановление пароля. Восстановление пароля, удаление аккаунта через интерфейс и персональный подбор карточек пока не реализованы.

Гостевые записи привязаны к адресу сайта и браузеру: localhost и GitHub Pages имеют разные местные данные. Облачный дневник доступен после входа в тот же аккаунт.
